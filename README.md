# An-lise_de_Dados_Banc-rios_Comportamento_Financeiro_de_Clientes
Neste projeto, desenvolvi e analisei um banco de dados fictício contendo informações financeiras de 1000 clientes de uma instituição bancária. O objetivo é entender o perfil financeiro dos clientes através de variáveis como idade, gênero, estado civil, saldo bancário, salário mensal, limite de cartão de crédito, score de crédito...
