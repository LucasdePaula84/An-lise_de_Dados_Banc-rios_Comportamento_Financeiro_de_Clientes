Análise de Dados Bancários: Comportamento Financeiro de Clientes

Neste projeto, desenvolvi e analisei um banco de dados fictício contendo informações financeiras de 1000 clientes de uma instituição bancária.
O objetivo é entender o perfil financeiro dos clientes através de variáveis como idade, gênero, estado civil, saldo bancário, salário mensal, limite de cartão de crédito, score de crédito, número de empréstimos, tipo de conta, entre outros.

A partir desse banco de dados, realizamos análises exploratórias para identificar padrões, tendências e insights estratégicos, como:
• A média de idade dos clientes;
• A relação entre saldo bancário e idade;
• O impacto do score de crédito na quantidade de empréstimos;
• Comparações salariais entre investidores e não investidores;
• Diferenças no limite de crédito conforme o tipo de conta;
• Evolução do número de clientes ao longo dos anos;
• Distribuição de gênero entre os tipos de conta;
• Perfil dos clientes inadimplentes.

Essas análises são essenciais para apoiar decisões bancárias mais assertivas, como concessão de crédito, criação de produtos financeiros e definição de estratégias de retenção e atração de clientes.

# 2. Faixa de saldo bancário por idade

# Criar faixas etárias
bins = [20, 30, 40, 50, 60, 70, 80]
labels = ['20-30', '31-40', '41-50', '51-60', '61-70', '71-80']

df['Faixa_Idade'] = pd.cut(df['Idade'], bins=bins, labels=labels, right=True)

# Agrupar saldo médio por faixa etária
saldo_por_faixa = df.groupby('Faixa_Idade')['Saldo_Conta'].mean()

# Plotar o gráfico
plt.figure(figsize=(8,5))
saldo_por_faixa.plot(kind='bar', color='mediumpurple')
plt.title('Saldo Bancário Médio por Faixa Etária')
plt.xlabel('Faixa Etária')
plt.ylabel('Saldo Bancário Médio (R$)')
plt.grid(axis='y')
plt.xticks(rotation=45)
plt.show()
